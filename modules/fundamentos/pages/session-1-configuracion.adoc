= Configuración del entorno de desarrollo con Swift

Esta práctica complementa la introducción a Swift cubriendo la configuración del entorno que utilizaremos para ejecutar los primeros ejemplos del lenguaje.

En el aula trabajaremos principalmente con **macOS y Xcode**. Se incluyen también instrucciones detalladas para Linux y Windows para quienes utilicen su propio portátil o quieran reproducir el entorno en casa.

====
.Objetivos de la práctica
- Comprobar el entorno Swift incluido con Xcode en macOS.
- Instalar y configurar Swift en Linux y Windows.
- Familiarizarse con herramientas de línea de comandos para Swift.
- Ejecutar código Swift tanto desde Xcode como desde la terminal.
- Utilizar el compilador `swiftc` y el REPL como herramientas complementarias.
====

== Introducción
Swift es un lenguaje de código abierto y dispone de toolchains oficiales para **macOS, Linux y Windows**. En macOS, Xcode proporciona el entorno completo para desarrollar aplicaciones para las plataformas de Apple. En Linux y Windows podemos utilizar el mismo lenguaje y sus herramientas para programas de consola y otros tipos de aplicaciones multiplataforma.

En esta sesión utilizaremos herramientas básicas como el compilador `swiftc` y el REPL (_Read-Eval-Print Loop_). **Swift Package Manager se verá más adelante.**

== Configuración en macOS

=== Xcode y Playgrounds

En los equipos del aula utilizaremos Xcode como entorno principal. Xcode incluye el toolchain de Swift necesario para compilar y ejecutar los ejemplos.

Para comprobar el entorno:

. Abre Xcode.
. Selecciona **File > New > Playground...**.
. Elige una plantilla vacía.
. Escribe:

[source,swift]
----
print("¡Hola, Swift!")
----

. Ejecuta el Playground y comprueba la salida.

=== Comprobación desde la terminal

La terminal es un complemento útil incluso cuando trabajamos con Xcode. Puedes consultar la versión incluida en el toolchain activo con:

[source,bash]
----
xcrun swift --version
----

En muchos equipos también podrás ejecutar directamente:

[source,bash]
----
swift --version
----

La salida concreta dependerá de la versión de Xcode instalada.

== Configuración en Linux
Linux es una plataforma bien soportada para Swift. Puedes instalar Swift utilizando paquetes precompilados o compilando desde el código fuente.

=== Instalación recomendada con Swiftly
Swiftly es una herramienta oficial para instalar y gestionar versiones de Swift de manera sencilla. La forma recomendada es usar Swiftly para instalar Swift.

* Instala Swiftly ejecutando los siguientes comandos en la terminal:
[source,bash]
----
curl -O https://download.swift.org/swiftly/linux/swiftly-$(uname -m).tar.gz && \
tar zxf swiftly-$(uname -m).tar.gz && \
./swiftly init --quiet-shell-followup && \
. "${SWIFTLY_HOME_DIR:-$HOME/.local/share/swiftly}/env.sh" && \
hash -r
----

* Una vez instalado Swiftly, instala la última versión de Swift:
[source,bash]
----
swiftly install latest
----

La salida esperada durante la instalación podría ser similar a la siguiente. La versión concreta puede cambiar conforme se publiquen nuevas versiones estables:

Swiftly comprueba también las dependencias necesarias para la distribución instalada. Si falta alguna, sigue las instrucciones que muestre la propia herramienta. Es preferible hacerlo así a mantener una lista fija de paquetes, ya que cambia según la distribución y su versión.

Si encuentras errores como paquetes no disponible, intenta actualizar la lista de paquetes con:
[source,bash]
----
sudo apt-get update
----

Si Swift no está disponible en nuevas sesiones de terminal, swiftly debería cargar automáticamente el entorno al iniciar la sesión. Si no es así, ejecuta:
[source,bash]
----
source ~/.bashrc
----
o reinicia la terminal. Si el problema persiste, verifica que swiftly haya modificado correctamente tu archivo de perfil (~/.bashrc o ~/.zshrc). Si es necesario, añade manualmente la siguiente línea a tu ~/.bashrc:
[source,bash]
----
. "${SWIFTLY_HOME_DIR:-$HOME/.local/share/swiftly}/env.sh"
----

=== Verificación de la instalación
Abre una terminal y ejecuta:
[source,bash]
----
swift --version
----
Deberías ver la versión de Swift instalada.

La versión y el _target_ dependerán del toolchain y arquitectura instalados.

=== Usando el REPL
El REPL de Swift te permite ejecutar código interactivamente. Ejecuta:
[source,bash]
----
swift repl
----
Ahora puedes escribir código Swift directamente en la terminal. Por ejemplo:
[source,swift]
----
let saludo = "¡Hola, Swift en Linux!"
print(saludo)
----

La salida en el REPL podría ser similar a la siguiente:
[source,console]
----
frangarcj@ADMATIC:~$ swift repl
  1> let saludo = "¡Hola, Swift en linux!"
saludo: String = "¡Hola, Swift en linux!"
  2> print(saludo)
¡Hola, Swift en linux!
  3>  
----

Presiona `Ctrl+D` para salir del REPL.

=== Compilando y ejecutando código
Crea un archivo `hola.swift` con el siguiente contenido:
[source,swift]
----
print("¡Hola, Swift!")
----
Compila y ejecuta:
[source,bash]
----
swiftc hola.swift
./hola
----

== Configuración en Windows
Swift dispone actualmente de **toolchain nativo oficial para Windows**. Para los ejercicios de esta asignatura no es necesario utilizar WSL.

=== Requisitos

La instalación oficial utiliza **WinGet** y requiere las herramientas de C++ y el SDK de Windows proporcionados por Visual Studio 2022. También es recomendable habilitar el **Developer Mode** de Windows.

=== Instalación de las dependencias de plataforma

Abre PowerShell y ejecuta:

[source,powershell]
----
winget install --id Microsoft.VisualStudio.2022.Community --exact --force --custom "--add Microsoft.VisualStudio.Component.Windows11SDK.22621 --add Microsoft.VisualStudio.Component.VC.Tools.x86.x64 --add Microsoft.VisualStudio.Component.VC.Tools.ARM64" --source winget
----

Este comando instala Visual Studio Community junto con los componentes necesarios para compilar programas Swift en Windows.

=== Instalación del toolchain de Swift

[source,powershell]
----
winget install --id Swift.Toolchain -e --source winget
----

Una vez terminada la instalación, cierra y vuelve a abrir PowerShell si fuera necesario para actualizar el entorno.

=== Verificación y uso
Comprueba que Swift está disponible:

[source,powershell]
----
swift --version
----

El mismo fichero `hola.swift` utilizado en Linux puede compilarse en Windows:

[source,powershell]
----
swiftc hola.swift -o hola.exe
.\hola.exe
----

=== Visual Studio Code

Para una experiencia de edición más completa fuera de Xcode puedes utilizar Visual Studio Code.

* Descarga e instala Visual Studio Code.
* Instala la extensión oficial **Swift**.
* Abre la carpeta que contiene tus ficheros `.swift`.
* Puedes utilizar la terminal integrada para ejecutar `swift` y `swiftc`.

La extensión oficial proporciona autocompletado, navegación, depuración y otras herramientas de desarrollo.

La documentación oficial de instalación está disponible en https://www.swift.org/install/windows/[swift.org/install/windows].

== Consideraciones finales
- En el aula utilizaremos principalmente Xcode y Playgrounds.
- La terminal permite ejecutar y compilar los mismos ejemplos fuera del IDE.
- Linux utiliza Swiftly como gestor recomendado del toolchain.
- Windows dispone de soporte nativo oficial y no necesita WSL para estos ejercicios.
- Swift Package Manager se introducirá más adelante.
- La comunidad Swift proporciona recursos actualizados en https://swift.org/[swift.org].

= Configuración de Swift en otros sistemas operativos

Esta sesión complementa la introducción a Swift cubriendo la configuración del entorno de desarrollo en sistemas operativos distintos a macOS, como Linux y Windows. Aunque Xcode es el entorno principal para el desarrollo en el ecosistema Apple, Swift es un lenguaje de código abierto que se puede utilizar en otras plataformas para aprender, experimentar y desarrollar aplicaciones no específicas de Apple.

====
.Objetivos de la práctica
- Instalar y configurar Swift en Linux y Windows.
- Familiarizarse con herramientas de línea de comandos para Swift.
- Ejecutar código Swift básico sin Xcode.
- Comprender las limitaciones y alternativas para desarrollo en plataformas no-Apple.
====

== Introducción
Swift está disponible para Linux y Windows a través del proyecto oficial de Swift en GitHub. Esto permite a los desarrolladores aprender el lenguaje y crear aplicaciones que no dependan de frameworks específicos de Apple. Sin embargo, para desarrollar aplicaciones iOS, macOS, watchOS o tvOS, se requiere macOS con Xcode.

En esta sesión, aprenderemos a instalar Swift en Linux y Windows, y a utilizar herramientas básicas como el compilador `swiftc`, el REPL (Read-Eval-Print Loop) y el Swift Package Manager.

== Configuración en Linux
Linux es una plataforma bien soportada para Swift. Puedes instalar Swift utilizando paquetes precompilados o compilando desde el código fuente.

=== Instalación recomendada con Swiftly
Swiftly es una herramienta oficial para instalar y gestionar versiones de Swift de manera sencilla. La forma recomendada es usar Swiftly para instalar Swift.

* Instala Swiftly ejecutando los siguientes comandos en la terminal:
[source,bash]
----
curl -O https://download.swift.org/swiftly/linux/swiftly-$(uname -m).tar.gz && \
tar zxf swiftly-$(uname -m).tar.gz && \
./swiftly init --quiet-shell-followup && \
. "${SWIFTLY_HOME_DIR:-$HOME/.local/share/swiftly}/env.sh" && \
hash -r
----

* Una vez instalado Swiftly, instala la última versión de Swift:
[source,bash]
----
swiftly install latest
----

[source,bash]
----
. "${SWIFTLY_HOME_DIR:-$HOME/.local/share/swiftly}/env.sh"
----

=== Verificación de la instalación
Abre una terminal y ejecuta:
[source,bash]
----
swift --version
----
Deberías ver la versión de Swift instalada.

[source,console]
----
Swift version 6.2 (swift-6.2-RELEASE)
Target: x86_64-unknown-linux-gnu
----

=== Usando el REPL
El REPL de Swift te permite ejecutar código interactivamente. Ejecuta:
[source,bash]
----
swift repl
----
Ahora puedes escribir código Swift directamente en la terminal. Por ejemplo:
[source,swift]
----
let saludo = "¡Hola, Swift en Linux!"
print(saludo)
----

La salida en el REPL podría ser similar a la siguiente:
[source,console]
----
frangarcj@ADMATIC:~$ swift repl
  1> let saludo = "¡Hola, Swift en linux!"
saludo: String = "¡Hola, Swift en linux!"
  2> print(saludo)
¡Hola, Swift en linux!
  3>  
----

Presiona `Ctrl+D` para salir del REPL.

=== Compilando y ejecutando código
Crea un archivo `hola.swift` con el siguiente contenido:
[source,swift]
----
print("¡Hola, Swift!")
----
Compila y ejecuta:
[source,bash]
----
swiftc hola.swift
./hola
----

== Configuración en Windows
Windows tiene soporte limitado para Swift comparado con macOS y Linux. Actualmente, Swift se puede instalar en Windows a través de subsistemas o contenedores.

=== Usando Windows Subsystem for Linux (WSL)
La forma más recomendada es utilizar WSL para ejecutar una distribución de Linux dentro de Windows.

* Habilita WSL en Windows: Abre PowerShell como administrador y ejecuta:
[source,powershell]
----
wsl --install -d Ubuntu-22.04
----

La salida esperada en la consola podría ser similar a la siguiente:
[source,console]
----
Instalando: Ubuntu 22.04 LTS
Se ha instalado Ubuntu 22.04 LTS.
Iniciando Ubuntu 22.04 LTS...
Installing, this may take a few minutes...
Please create a default UNIX user account. The username does not need to match your Windows username.
For more information visit: https://aka.ms/wslusers
Enter new UNIX username: frangarcj
New password:
Retype new password:
passwd: password updated successfully
Installation successful!
----

* Una vez instalado, sigue los pasos de instalación en Linux descritos anteriormente.

=== Verificación y uso
Después de configurar WSL, puedes usar Swift como en Linux. Abre la terminal de WSL y verifica con `swift --version`.

=== Limitaciones en Windows nativo
Actualmente, no hay soporte nativo completo para Swift en Windows fuera de WSL. Para desarrollo avanzado, se recomienda usar macOS o Linux.

=== Instalando Visual Studio Code y WSL Remote
Para una mejor experiencia de desarrollo en Windows con WSL, instala Visual Studio Code y la extensión WSL Remote.

* Descarga e instala Visual Studio Code desde https://code.visualstudio.com/
* Abre VS Code e instala la extensión "WSL" desde el marketplace (busca "WSL" de Microsoft).
* Para conectar a WSL: Abre la paleta de comandos (Ctrl+Shift+P) y selecciona "WSL: Connect to WSL using Distro". Elige la distribución instalada, como Ubuntu 22.04.

Esto te permitirá editar archivos o usar la terminal de WSL directamente desde VS Code.

== Swift Package Manager
El Swift Package Manager (SPM) es una herramienta para gestionar dependencias y construir proyectos Swift. Está disponible en todas las plataformas soportadas.

=== Creando un proyecto simple
* Crea un directorio para tu proyecto:
[source,bash]
----
mkdir MiProyecto
cd MiProyecto
----
* Inicializa un paquete:
[source,bash]
----
swift package init --type executable
----
* Edita `Sources/main.swift` con tu código.
* Construye y ejecuta:
[source,bash]
----
swift build
swift run
----

== Consideraciones finales
- Para desarrollo de aplicaciones iOS/macOS, macOS con Xcode es esencial.
- En Linux y Windows, puedes aprender Swift, crear herramientas de línea de comandos y aplicaciones server-side.
- La comunidad Swift proporciona recursos adicionales en el sitio oficial: https://swift.org/
